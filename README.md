# 💫 About Me

🎓 **Software Engineer** with a B.Sc. in Computer Engineering, focused on backend development with **Java and Spring Boot**, building clean, scalable and maintainable server-side applications.

🧠 Experienced in designing RESTful APIs following SOLID principles, Clean/Layered Architecture, Microservices and Event-Driven Architecture, with a strong emphasis on readability and long-term maintainability.

🔐 Hands-on with secure authentication (JWT, RBAC, Spring Security), email services, Redis caching and Stripe payment integration.

🤖 Interested in AI-powered backend systems: RAG, LLM integration, vector search (pgvector) and Spring AI.

🗄 Experience with PostgreSQL, MySQL, MSSQL and Redis for data persistence, caching and performance optimization; messaging with RabbitMQ.

🧪 Writing unit and integration tests with JUnit 5 and Mockito to ensure reliability and confidence in code changes.

🚀 Passionate about backend performance, database design, and building secure, efficient, developer-friendly APIs.
